Student Management System

A simple Student Management System built with C++.

The project is designed to practice the basics of C++ programming and object-oriented programming while building a small practical application for managing student data.

Features

- Add new students
- Display all students
- Search for a student
- Update student information
- Delete a student
- Store student data using "vector"
- Simple menu-based interface

Technologies Used

- C++
- STL
- Vector
- Object-Oriented Programming

Project Structure

Student-Management-System/
│
├── main.cpp
└── README.md

How to Run

Compile the project using any C++ compiler:

g++ main.cpp -o student_management

Then run:

./student_management

Purpose

This project was created as a practical application of C++ concepts, especially "vector", classes, functions, and basic CRUD operations.

It is a simple project, but it helped me practice writing a complete program and organizing different operations in one application.
